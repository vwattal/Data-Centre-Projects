💬 Set up Teams Direct Messages

One-time setup via Power Automate (~5 min):
  1. Go to flow.microsoft.com (sign in with your Intel account)
  2. Click + New flow → Instant cloud flow → pick "When an HTTP request is received" → Create
  3. In the trigger card, click "Use sample payload to generate schema" → paste this → Done: 
    {"to":"user@intel.com","bug_id":"123","bug_title":"test","note":"hi"}
  4. Click + New step → search Microsoft Teams → choose "Post a message in a chat or channel"
  5. Set fields:
    • Post in: Chat with someone
    • Recipient: click the field → pick to from Dynamic content
    • Message: click the field → mix in bug_id, bug_title, note from Dynamic content as you like
  6. Click Save. Then go back to the "When an HTTP request is received" step → copy the HTTP POST URL
  7. Paste that URL below → Save
After saving, type @username in any Comments cell and click away — each person gets a 1-on-1 Teams DM from you.

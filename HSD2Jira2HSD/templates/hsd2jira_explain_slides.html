🔗 HSD2Jira

How It Works — Decision Logic

For each HSD returned by the cron queries, the tool decides whether to create Jira issues or skip.

If a Jira is created, a 9-issue hierarchy is built (Epic → 3 Parent Stories → 3 Child Stories → Upstream Task → Child Story) in project VLK.
The CC Story key is written back to the HSD child so the cron is idempotent — any HSD that already has a Jira key is skipped.

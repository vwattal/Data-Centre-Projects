📖 How HSD2Jira Works

For each HSD returned by the cron queries, the tool decides whether to create Jira issues or skip.
Below is the decision logic for each tenant, followed by a quick-reference condition table.

🖥 View as Slides 📥 Download .pptx
The CC Story key is written back to a field on the HSD child record so the cron is idempotent — it will skip any HSD that already has a Jira key written.

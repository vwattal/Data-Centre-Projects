🔍 Process HSD Query

Accepts a query URL (?queryId=…) or a single HSD article URL.

server.feature — JGS/CRI KMD feature HSDs:
1️⃣ Find server.ar children where title = SW Arch Review, component ∈ sw.xe_kmd / sw.ual_kmd, exposure ≠ none / to_be_assigned
2️⃣ For each: check for a corresponding server.ar child with title = SW Development Review and same component
   • If SW Dev Review exists & jira_key already set → skip
   • If SW Dev Review exists & jira_key empty → create Epic + 8 Jira issues & write back jira_key
   • If SW Dev Review missing → create it (same component, same exposure), create Epic + 8 Jira issues & write jira_key = CC story key
   • Platform auto-detected from family_affected: Jaguar Shores → Jaguar Shores + tag JGS
   • Component mapping: sw.xe_kmd → XeKMD / guptasa2  |  sw.ual_kmd → Kernel - UAL / myossefi

dg_soc.feature — for each HSD in the query, two paths run independently:
i915_kmd path — uses exposure from task=architecture child if present, otherwise from task=development child:
   • exposure = none / to_be_assigned → skip i915_kmd (HSD may still be processed via UAL path)
   • i915_kmd / development child exists with empty jira_key → reuse it, create Epic + 8 Jira issues, write back jira_key
   • No development child → create new dg_soc.ar child (team=i915_kmd, task=development, type=sw_assessment), create Jira, write back
   • Component = XeKMD / assignee = mtangri
sw.ual_kmd path — checked independently regardless of i915_kmd result:
   • sw.ual_kmd / development child with valid exposure and empty jira_key → create Epic + 8 Jira issues, write back jira_key
   • Component = Kernel - UAL / assignee = jzuo2
Both paths: creates Epic · CC Parent Story (labeled {TAG}_DCN_Query) · 2 CC Child Stories · IGT Story (component: Test-Core) · Sim Story · Emu Story · Upstream Task · Upstream Child Story
Skips the entire HSD only if no i915_kmd or sw.ual_kmd development/architecture child exists at all.

server_platf.feature — for each HSD in the query:
1️⃣ Find the server_platf.ar child whose title contains KMD / XeKMD / Xe KMD
2️⃣ Create Epic + 8 Jira issues in VLK
3️⃣ Write the CC parent story key to the matched AR child's tag field

ip_hw_graphics.bugeco — SW Workaround bugs:
1️⃣ Find the ip_hw_graphics.sw_impact child where sw_component = i915_kmd and func_impact = wa_needed
2️⃣ Create Epic + 8 Jira issues in VLK
3️⃣ Write the CC parent story key to ip_hw_graphics.sw_impact.sw_record
   • Skipped if sw_record is already populated

ip_hw_graphics.feature — HW Feature HSDs with SW impact:
1️⃣ Gate: find ip_hw_graphics.sw_impact child where sw_component=core, os=common, sw_task=architecture, sw_exposure ≠ to_be_assigned / none
2️⃣ If i915_kmd / linux / development child exists: skip if sw_record is set; else create Epic + 8 Jira issues in VLK & write back sw_record
3️⃣ If no kmd dev child: create ip_hw_graphics.sw_impact child (sw_component=i915_kmd, sw_task=development, os=linux, same sw_exposure, owner=guptasa2), create Epic + 8 Jira issues in VLK & write back sw_record
Required. [TAG] is prepended to every Jira title and TAG_DCN_Query label is added to the CC parent story.
